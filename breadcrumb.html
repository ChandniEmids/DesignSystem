Component
Breadcrumb
Secondary navigation showing the user's location within the app hierarchy.
Purpose

Breadcrumbs show the user's current location within the app hierarchy and provide a quick path back to any parent level. They appear at the top of detail and sub-section pages, always reflecting the exact page titles in the order they were navigated. The current page is shown as plain text — the rest are underlined links.

Last item is never a link
The current page (rightmost item) is always plain text — not underlined, not clickable. It shows where the user is, not where they can go.
Max 4 levels
Breadcrumbs beyond 4 levels create cognitive overload. Collapse middle items with an ellipsis if the hierarchy is deeper than 4.
Match page titles exactly
Each breadcrumb label must match the actual page or section title. Never shorten or paraphrase — users rely on exact names to navigate back.
Separator is decorative
The "/" separator is visual only — it carries no semantic meaning and must be hidden from screen readers using aria-hidden.
