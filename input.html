Input Field
6 states · Outlined floating label on border · 8px radius · Manrope 16px
Purpose

The Input Field is the primary text entry component in ClearPath FDO. It uses a floating label pattern — the label sits on the border of the input box, keeping the field compact while always showing the field name. Six states cover every interaction: Default, Hover, Focused, Filled, Disabled, and Error.

Label always visible
The floating label sits on the border at all times — it never disappears inside the field. Users always know what the field is for, even after typing.
Error below the field
Error messages appear directly below the input box, never inside it. The border turns red and the label colour changes to match — never rely on colour alone.
Disabled is not editable
Disabled inputs use a grey background and muted label. They are visible but non-interactive. Never hide a disabled field — always show it so users understand the form structure.
Placeholder is not a label
Placeholder text provides an example value, not the field name. Never use a placeholder as the only label — it disappears on typing and fails accessibility requirements.
