Foundation
Icons
Token-based icon system using Tabler Icons (outline). Single source of truth for all iconography across ClearPath FDO.
Purpose

Icons are a foundation asset, not a component. They carry meaning through visual shorthand — reducing cognitive load for staff who navigate the same interface dozens of times per day. This system uses a single icon library (Tabler Icons, outline style) with token-based sizing and semantic color rules. No custom SVGs, no mixed libraries, no arbitrary sizes.

Single library
Tabler Icons (outline) is the only source. No Heroicons, Feather, or custom SVGs — ever.
Three sizes only
sm · md · lg. No arbitrary pixel values. Size is always set via a token, never hardcoded.
Color inherits
Icons inherit color from their parent by default. Override only with semantic tokens — never raw hex.
Pair with text
Icons must be paired with a visible text label wherever clarity is required. Icon-only use is permitted only for universally understood actions (close, search).
Dos & Don'ts
Do
  • Use only Tabler Icons outline style — verify names at tabler.io before using.
  • Apply size via the defined token scale: sm (16px) · md (20px) · lg (24px).
  • Let color inherit from the parent element; override only with a semantic color token.
  • Pair icons with a text label in navigation, buttons, and form fields.
  • Use aria-label on standalone interactive icons for screen reader support.
Don't
  • Don't use filled, two-tone, or mixed-style icons — outline only.
  • Don't set arbitrary sizes like 12px, 14px, 18px — use only sm, md, lg tokens.
  • Don't apply raw hex colours to icons — use semantic tokens or color inheritance.
  • Don't stretch or distort icons by setting mismatched width/height.
  • Don't use icon-only controls for ambiguous actions — always pair with a label or tooltip.

Accessibility
Requirement Rule
Decorative iconsAdd aria-hidden="true" to icons that are paired with a visible text label — they carry no additional meaning for screen readers.
Standalone iconsStandalone interactive icons (e.g. close button, search trigger) must have aria-label="[action]" on the containing button element.
Status iconsIcons used to convey status (warning, error, success) must not rely on the icon alone. Always accompany with a visible text label or a role="status" region.
Color contrastIcon color against its background must meet WCAG AA (3:1 for UI components). Disabled icons are exempt. Never use color as the only differentiator.
Keyboard targetsInteractive icon buttons must have a minimum click/tap target of 40×40px, even if the icon itself is 16px. Use padding on the containing <button> to achieve this.
Developer Usage

All icons use the Tabler Icons webfont via CDN. The icon class follows the pattern ti ti-[name]. Size is applied via font-size using the token value directly.

CDN Link (add to <head>)
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@tabler/icons-webfont@latest/dist/tabler-icons.min.css">
Basic Usage — Size & Color
<!-- Default (inherits parent color) -->
<i class="ti ti-calendar" style="font-size:16px;"></i>

<!-- sm — 16px -->
<i class="ti ti-calendar" style="font-size:var(--font-size-md);"></i>

<!-- md — 20px -->
<i class="ti ti-calendar" style="font-size:20px;"></i>

<!-- lg — 24px -->
<i class="ti ti-calendar" style="font-size:24px;"></i>

<!-- Primary color -->
<i class="ti ti-calendar" style="font-size:16px;color:var(--brand-blue);"></i>

<!-- Disabled -->
<i class="ti ti-calendar" style="font-size:16px;color:var(--text-muted);"></i>
Decorative — Paired with Label
<button class="btn-primary">
  <i class="ti ti-plus" aria-hidden="true" style="font-size:16px;"></i>
  New Appointment
</button>
Standalone Interactive — Accessible
<!-- Close button — icon only, must have aria-label -->
<button class="btn-icon" aria-label="Close panel">
  <i class="ti ti-x" style="font-size:16px;"></i>
</button>

<!-- Search trigger -->
<button class="btn-icon" aria-label="Search">
  <i class="ti ti-search" style="font-size:16px;"></i>
</button>
Status Icon — With Text
<!-- Warning — icon must NOT be the sole indicator -->
<span style="display:inline-flex;align-items:center;gap:8px;color:var(--color-warning-text);">
  <i class="ti ti-alert-triangle" aria-hidden="true" style="font-size:16px;"></i>
  <span>Overdue</span>
</span>

<!-- Success -->
<span style="display:inline-flex;align-items:center;gap:8px;color:var(--color-success-text);">
  <i class="ti ti-circle-check" aria-hidden="true" style="font-size:16px;"></i>
  <span>Completed</span>
</span>
