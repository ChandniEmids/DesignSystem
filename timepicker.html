Component
Timepicker
Extends the Input component with a scrollable time panel supporting 12hr and 24hr formats.
Purpose

The Timepicker extends the outlined floating-label Input with a clock icon trigger and a scrollable dropdown for hour and minute selection. Supports both 12-hour (AM/PM) and 24-hour formats. Both keyboard input and scroll/click selection are supported simultaneously — users choose their preferred interaction mode.

Extends Input
Same floating-label outlined input. All six states — default, hover, focused, filled, disabled, error — inherited unchanged.
Dual Format
Toggle between 12hr and 24hr at the top of the panel. Format persists per field instance, defaults to 12hr.
Keyboard Input
Segment inputs allow direct typing of HH MM. Up/down arrows increment values. Backspace clears segment.
Accessible
aria-label on all controls, role="listbox" on columns, aria-selected on items, scroll-snap for predictable selection.
Input States

Timepicker input inherits all base Input states — no new styling added to the field itself.

Edge Cases
ScenarioBehavior
Empty (no selection)Input shows placeholder. Panel opens with no selection highlighted. Hour column scrolls to top.
Invalid time (25:99)Input enters Error state with message "Please enter a valid time." Value is not committed.
Keyboard: out-of-range digitInvalid digit is rejected silently. Focus stays on segment.
Disabled fieldClock icon non-interactive. Panel never opens. Field reads as disabled.
Format switch mid-sessionCurrent value converts to new format. 13:00 → 1:00 PM. 1:00 PM → 13:00.
Minute step granularityDefault step is 5 min. Can be configured to 1 min or 15 min via a data-step attribute.
Long value (24hr overflow)Input width fixed; value never exceeds 5 chars (HH:MM). No truncation needed.
