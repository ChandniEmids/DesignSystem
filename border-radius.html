Border Radius
Corner radius primitives and component usage rules

Border radius in ClearPath FDO uses a deliberate 7-step scale from sharp (0px) to pill (9999px). Every corner treatment maps to a named semantic token — ensuring corners feel intentional and consistent across the entire UI.

Consistent Softness
All UI elements of the same type share the same radius. Inputs, buttons, and cards never vary from their designated token.
Named by Value
Tokens are named by their pixel value (--radius-8, --radius-12…) so the intent is immediately readable in code.
Clinical Restraint
Healthcare UI requires trust. Radius is used sparingly — enough to soften hard edges without appearing playful.
Size Signals Hierarchy
Larger radius for larger surfaces: sm for inline elements, md for controls, lg for containers, pill for status indicators.

Usage Rules
Default is 8
Use radius-8 as the baseline

Inputs, buttons, chips, selects, and nav items all use --radius-8 by default unless explicitly overridden for a larger surface.

Size Signals Hierarchy
Larger radius = larger container

Badges/chips use --radius-6. Controls use --radius-8. Cards use --radius-12. Modals use --radius-16.

No Raw Values
Never hardcode corner values

Never write border-radius: 8px. Always use var(--radius-8) so global corner changes propagate automatically.

No 50% for Circles
Use radius-full, not 50%

For circular avatars and pill badges, use --radius-full (9999px). Using 50% can distort non-square elements unpredictably.

Dos & Don'ts
Do
  • Use --radius-8 for all input fields and buttons
  • Use --radius-6 for badges and compact chips
  • Use --radius-12 for appointment cards and panels
  • Use --radius-full for user avatars and status dots
Don't
  • Don't write raw values like border-radius: 10px — it's off-scale
  • Don't mix radius tokens within a single component
  • Don't use border-radius: 50% for pill shapes — use --radius-full
  • Don't apply large radii (--radius-16, --radius-24) to small inline components
CSS Custom Properties

All radius tokens live in global.css — Layer 1 for raw values, Layer 2 for semantic names.

Border Radius Tokens
/* global.css — Border Radius */
:root {
  --radius-0:    0px;
  --radius-4:    4px;
  --radius-6:    6px;
  --radius-8:    8px;
  --radius-12:   12px;
  --radius-16:   16px;
  --radius-24:   24px;
  --radius-full: 9999px;
}
Example Usage
/* Input field */
.field input {
  border-radius: var(--radius-8);
}

/* Status badge */
.badge {
  border-radius: var(--radius-6);
}

/* Appointment card */
.appointment-card {
  border-radius: var(--radius-12);
}

/* Modal dialog */
.modal-panel {
  border-radius: var(--radius-16);
}

/* User avatar */
.user-avatar {
  border-radius: var(--radius-full);
}
