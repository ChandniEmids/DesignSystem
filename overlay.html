Purpose

Overlays surface contextual content, confirmations, and extended panels without navigating away from the current screen. ClearPath FDO uses three overlay patterns: Modals for focused actions and confirmations, Tooltips for inline help text, and Drawers for extended side panels that preserve page context.

One overlay at a time
Never stack modals or open a drawer while a modal is active. Nested overlays disorient users and make it unclear how to dismiss them.
Always dismissible
Every overlay must be closeable via Escape key, the close button, and clicking the backdrop. Never trap a user inside an overlay without an exit path.
Danger type for destructive actions
Use the Danger modal exclusively for irreversible actions — deleting a patient record, cancelling an appointment. Never use Default styling for destructive confirmations.
Focus trap inside modal
When a modal opens, keyboard focus must be trapped inside it. Tab and Shift+Tab should only cycle through the modal's interactive elements until it is dismissed.
