Component
Datepicker
Extends the Input component with a calendar panel for selecting single dates or ranges.
Purpose

The Datepicker extends the existing outlined floating-label Input. It adds a calendar icon trigger and an attached calendar panel for selecting dates. Use it wherever a precise date is required — appointment booking, date-of-birth, scheduling windows. The base input component is unchanged; the calendar panel is layered on top.

Extends Input
No new input created. All field variants (hover, focus, error, disabled) inherit from the base Input component.
Keyboard Ready
Arrow keys navigate days, Enter selects, Escape closes, Tab moves focus through controls.
Today + Clear
Action strip provides quick access to today's date and a way to clear the selection without additional interactions.
Accessible
aria-label on all controls, role="dialog" on the panel, aria-selected on days, focus trap when open.

Edge Cases
Scenario Behavior
Empty (no selection) Input shows placeholder state. Calendar opens with current month highlighted.
Invalid / out-of-range date Input transitions to Error state. Error message shown below. Calendar highlights invalid day in muted style.
Min/max date constraints Days outside allowed range rendered with .disabled-day — not interactive.
Long date format Input truncates with ellipsis. Full value visible in tooltip / aria-label.
Disabled field Calendar icon not interactive. Field reads as disabled. No dropdown opens.
Very long month/year Nav title truncates at 180px; ellipsis applied.
Range: start > end Swap dates silently — earlier date becomes start.
