| Term | Meaning |
|---|---|
| Surescripts | Health Information Network — middleware for e-prescriptions in the US |
| NCPDP | National Council for Prescription Drug Programs — the standard |
| New RX | Transaction for a brand-new prescription from doctor to pharmacy |
| Renewal Request | Transaction when a patient's pharmacy requests a refill from the prescriber |
| ERX | Electronic prescription — general term |
| EHR | Electronic Health Record — cross-organisation, supports hospitalisation |
| EMR | Electronic Medical Record — single organisation only |
| HTV | Health Tech Vendor — another term for EHR companies |
| PBM | Pharmacy Benefit Manager — handles insurance formulary and drug coverage |
| SPI | Surescripts Prescriber ID — identifies prescriber/EHR on the network |
| NCPDP ID | Unique ID for a pharmacy on the Surescripts network |
| RTPB | Real-Time Pharmacy Benefit |
| EPA | Electronic Prior Authorization |
| PPT | Patient Price Transparency — Team 36 app |
| Onboarding Modernization | Initiative to reduce 57 → 9 hrs per upgrade cycle |
| Stage environment | Customer-accessible test environment for certification work |
| Devint | Dev/integration environment — internal first step before Stage |
| Production | Live environment — where customers go after successful certification |
| Workbench | Platform where all certification work lives |
| Aha | Current work tracking tool (transitioning to JIRA) |
| Glue | Surescripts' internal design system |
| Galaxy / Hubble | Other Surescripts projects the team also works on |
| Certification v1 | First version of the certification tool — already launched |
| Test Step | Atomic unit — one message exchange |
| Test Case | Logical group of test steps |
| Test Project | Full collection of test cases for one customer's certification run |
| Account | The customer entity a test project is assigned to |
| Assertions | Rules that validate XML message fields during test execution |
| Message ID | Unique identifier on every outbound message |
| Relate To | Field linking a response step to its original request by Message ID |
| Autoresponder | RTPB feature that auto-generates responses based on patient ID matching |
| Direction | Which side sends — Customer Sends (SPI) vs Customer Receives (NCPDP ID) |
| HIN | Health Information Network — what Surescripts is |
| EMETS | Vendor organisation the design team belongs to |
