Component
Checkbox
Boolean selection control — Unchecked, Checked, Indeterminate, Disabled.
Purpose

Checkboxes are boolean selection controls that allow users to make multiple independent choices from a list. They support four states — Unchecked, Checked, Indeterminate, and Disabled. The indeterminate state is reserved for parent checkboxes in a group where only some children are selected.

Always has a visible label
Checkboxes must always pair with a text label. An icon-only or unlabelled checkbox is inaccessible and ambiguous.
Indeterminate for partial selection
Use the indeterminate state only when a parent checkbox represents a group where some — but not all — children are selected.
Multi-select only
Checkboxes allow multiple simultaneous selections. When only one option can be chosen, use a Radio button instead.
Keyboard accessible
Every checkbox must be focusable and togglable via Space. The focus ring must be visible. Never disable pointer-events without also disabling tab focus.
