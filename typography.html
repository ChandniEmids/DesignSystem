Typography Foundation
Type scale, weight system, line-height primitives, and semantic usage tokens

ClearPath FDO uses a two-layer typography model: primitive tokens define the raw scale values, and semantic tokens assign those primitives to roles in the UI. Components always reference semantic tokens — never raw pixel values — keeping the type system scalable and refactor-safe.

Scale Discipline
Seven sizes from xs (12px) to 3xl (32px). No one-off sizes like 13px or 15px.
Primitive → Semantic
Every semantic token maps only to primitives. No raw values in roles.
Readability First
Line heights are chosen for their use context: tight for headings, normal for body, relaxed for long-form content.
Clinical Clarity
Healthcare UIs demand legible, neutral type. No decorative or display fonts.

Usage Rules
Headings
Use for hierarchy only

h1 is reserved for page-level titles. h2 for section headings. h3 for card or panel headings. Never skip levels for visual size alone.

Body
Default reading context

Use text.body for all standard UI text. text.body.large for introductory or descriptive copy above fold.

Caption
Metadata and helper text

Use for timestamps, secondary descriptors, empty state help text, and form helper copy. Never use for interactive labels or primary content.

Labels
Form and navigation UI

label.form for input field labels and section dividers. label.nav for sidebar navigation items.

No Raw Values
Never use px or weights directly

Never write font-size: 14px in a component. Always reference a semantic token. Raw values break refactoring and theming.

No Color in Typography
Text color is a color token concern

Typography tokens define size, weight, and line-height only. Text color is set by color semantic tokens: --text-primary, --text-secondary.

Dos & Don'ts
Do
  • Use semantic class names like .ts-preview-body in components
  • Map new type roles to existing primitives first
  • Keep line-height paired to the role: tight for headings, normal for body
  • Always use Sentence case for UI text (not Title Case)
  • Pair label.form with a visible input field — never floating alone
Don't
  • Don't write raw pixel sizes like font-size: 13px in components
  • Don't mix heading levels for visual weight only — use font-weight
  • Don't use heading.h1 inside cards or modals
  • Don't add color values inside typography token definitions
  • Don't introduce sizes outside the defined scale (13px, 15px, 17px)
CSS Custom Properties

All typography tokens are defined in global.css under Layer 1 (primitives) and Layer 2 (semantics). Components use the semantic tokens only — never the primitives directly.

Layer 1 — Primitive Tokens
/* global.css — Layer 1: Typography Primitives */
:root {
  /* Font family */
  --font-family-primary: 'Manrope', sans-serif;
  --font-family-mono:    'Courier New', monospace;

  /* Font size scale (xs → 3xl) */
  --font-size-xs:  12px;
  --font-size-sm:  14px;
  --font-size-md:  16px;
  --font-size-lg:  18px;
  --font-size-xl:  20px;
  --font-size-2xl: 24px;
  --font-size-3xl: 32px;

  /* Font weight */
  --font-weight-regular:  400;
  --font-weight-medium:   500;
  --font-weight-semibold: 600;
  --font-weight-bold:     700;

  /* Line height */
  --line-height-tight:   1.2;  /* 120% — headings */
  --line-height-normal:  1.5;  /* 150% — body */
  --line-height-relaxed: 1.6;  /* 160% — long content */
}
Layer 2 — Semantic Tokens
/* global.css — Layer 2: Typography Semantics */
:root {
  /* Headings */
  --heading-h1-size:        var(--font-size-3xl);
  --heading-h1-weight:      var(--font-weight-bold);
  --heading-h1-line-height: var(--line-height-tight);

  --heading-h2-size:        var(--font-size-2xl);
  --heading-h2-weight:      var(--font-weight-bold);
  --heading-h2-line-height: var(--line-height-tight);

  --heading-h3-size:        var(--font-size-xl);
  --heading-h3-weight:      var(--font-weight-semibold);
  --heading-h3-line-height: var(--line-height-tight);

  /* Text */
  --text-body-size:             var(--font-size-md);
  --text-body-weight:           var(--font-weight-regular);
  --text-body-line-height:      var(--line-height-normal);

  --text-body-large-size:       var(--font-size-lg);
  --text-body-large-weight:     var(--font-weight-regular);
  --text-body-large-line-height: var(--line-height-normal);

  --text-caption-size:          var(--font-size-sm);
  --text-caption-weight:        var(--font-weight-regular);
  --text-caption-line-height:   var(--line-height-normal);

  /* Labels */
  --label-form-size:        var(--font-size-sm);
  --label-form-weight:      var(--font-weight-medium);
  --label-form-line-height: var(--line-height-normal);

  --label-nav-size:         var(--font-size-md);
  --label-nav-weight:       var(--font-weight-medium);
  --label-nav-line-height:  var(--line-height-normal);
}
