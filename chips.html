Component
Chip
Interactive compact elements for filtering, selecting values, and representing typed input as removable tokens.
Purpose

Chips are interactive compact elements that act like mini-buttons. Unlike badges — which the system sets and the user cannot change — chips are clickable and always produce a state change: a filter narrows results, a choice selects a value, an input chip removes a selected record from a set. Chips appear in filter bars, multi-select fields, and time-slot pickers.

Always interactive
Every chip must have a defined hover, focus, and active/selected state. Static chips are badges — not chips.
8px border-radius
Chips match button/input border-radius (8px) — not pill-shaped. Pill shape is reserved for badges only.
Lives in groups
Chips appear in horizontal lists or groups. A solitary chip with no siblings should be re-evaluated as a button.
Label always visible
Icons are optional, but text is always required. No icon-only chips — icons must pair with a text label.
Dos & Don'ts
Do
  • Define hover, focus, and selected states on every chip.
  • Keep chip labels 1–2 words maximum — chips are compact by design.
  • Use filter chips for narrowing lists; use choice chips for picking exactly one option.
  • Use input chips with a dismiss (×) button only when the value is removable.
  • Group chips in a flex row with consistent gap (6–8px).
Don't
  • Don't use pill shape (border-radius: 99px) on chips — that shape belongs to badges.
  • Don't create a chip that produces no state change — it is a badge.
  • Don't place chips inside form inputs or modal headers — use buttons there instead.
  • Don't omit the selected state — users must always know what is active.
  • Don't use the pulse dot on chips — that modifier is reserved for badges only.
Types & Inventory

Three chip types cover all interactive use cases in ClearPath FDO. Each type maps to a distinct interaction pattern.

1 — Filter Chip List views · Multi-criteria filter bars · Role/department filter

Narrows a list. Multiple can be active simultaneously. Uses 8px border-radius to match inputs and buttons — sits in a horizontal filter row alongside search inputs.

Active state shown in blue · Default is grey border
2 — Choice Chip Single-select from a fixed set · Slot/time pickers · Exclusive option groups

Selects exactly one value from a set. Selecting a new chip deselects the previous. Used for exclusive-choice groups such as time or slot pickers. Border-radius: 8px — matches input fields.

Accessibility
Requirement Rule
ElementUse <button> for filter and choice chips — not <span>. Input chips may use <span> with an inner <button> for the dismiss.
Focus ringAll chips must be keyboard-focusable with a visible 3px focus ring using var(--focus-ring).
Selected stateUse aria-pressed="true" on active filter chips. Use aria-selected="true" inside a role="listbox" for choice chips.
Dismiss buttonInput chip dismiss must have aria-label="Remove [patient name]" — the × character alone is not accessible.
ContrastAll chip labels must meet WCAG AA (4.5:1) against their background. Taken/disabled chips are exempt.
