Radio · Toggle · Toggle Group
Single-selection controls — Radio Button, Toggle Switch, and Segmented Toggle Group.
Purpose

This page covers three single-selection controls. Radio Buttons enforce one choice from a visible list. Toggle Switches represent an immediate binary on/off setting. Toggle Groups switch between a small set of named modes or views. Each control has a distinct use case — choosing the right one depends on whether the choice is immediate, binary, or one-of-many.

One selection only
Radio buttons enforce mutually exclusive choice. Selecting one automatically deselects the previous. Never allow zero selected in a required group.
Always grouped
A single radio button in isolation is meaningless. Always present at least 2 options. Use a checkbox when there is only one binary choice.
Toggle for binary on/off
Use a Toggle Switch for settings that take immediate effect (e.g. enable notifications). Use Radio for choices that require form submission to apply.
Toggle Group for views
Toggle Groups switch between predefined modes or views (e.g. Day / Week / Month). Keep labels short — 1–2 words — and limit to 5 options maximum.
