Token Structure
The naming convention used across all design tokens in ClearPath FDO.
Format
Category . Group . Property . State
Category what type
.
Group where used
.
Property what aspect
.
State optional
Rules
  • · Separate all words with . — never use - as a word separator
  • · State always comes last — color.nav.bg.active not color.nav.active.bg
  • · State is optional — omit it when there is only one state (e.g. color.text.primary)
Examples
color.nav.bg.active — nav item background when active
Category color It's a color token
Group nav Used in the sidebar navigation
Property bg Background fill
State active When the nav item is selected
color.text.primary — no state, only one value exists
Category color It's a color token
Group text Used for text / typography
Property primary The primary (strongest) text color
State — omitted, only one state exists
