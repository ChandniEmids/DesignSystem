Component
Alert
Inline feedback banners for Info, Success, Warning, and Danger — with and without dismiss.
Purpose

Alerts are inline feedback banners that communicate system-level messages in response to a user action or a background event. They come in four severity levels — Info, Success, Warning, and Danger — each using a distinct color and icon pair so the message type is immediately recognisable. Alerts can optionally be dismissed by the user.

Severity is always visible
Color and icon together communicate severity. Never rely on color alone — the icon must reinforce the message type.
Never auto-dismiss critical alerts
Warning and Danger alerts must stay visible until the user explicitly dismisses them. Only Info and Success may auto-dismiss.
One alert per context
Stack multiple alerts only when each message relates to a different part of the UI. Combine related messages into a single alert.
Title + description always
Every alert needs a short bold title and an actionable description. Never use a description without a title.
