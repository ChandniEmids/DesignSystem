Component
Avatar
Initials · Image · With Status · Nav · Profile Card  ·  6 sizes  ·  Teal gradient
Purpose

Avatars represent a user or entity visually — either as initials on a teal gradient, or a profile photo. They appear in headers, nav bars, patient records, and profile cards. Five variants cover every context: standalone initials, image-based, status-tagged, nav-embedded, and the full profile card.

Initials are always 2 characters
Use the first letter of first name and last name. Never show a full name, number, or icon inside an initials avatar — consistency matters at small sizes.
Status dot is always bottom-right
The status indicator sits at the bottom-right of the avatar with a 2px white border. Never move it to another corner — users learn to look there.
Match size to context
XS/SM for dense lists and table rows. MD for cards and comments. LG/XL for profile headers. 2XL for settings pages. Never scale manually — always use the size tokens.
Image fallback to initials
If a profile photo fails to load, always fall back to the initials variant with the teal gradient — never show a broken image or an empty circle.
